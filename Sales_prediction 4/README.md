# 📊 Sales Prediction Analysis
Accurately forecast business sales by analyzing advertising investment across TV, Radio, and Newspaper.

## 📋 Project Highlights
- **Goal**: Predict sales based on cross-platform advertising budgets.
- **Optimization**: Used `GridSearchCV` for hyperparameter tuning.
- **Winner**: The **Gradient Boosting Regressor** achieved a stellar **96% Accuracy**.
- **Analysis**: Conducted **Residual Analysis** to verify the model's error distribution.

## 🛠️ Technology Stack
- **Language**: Python 3.13
- **Primary Libraries**: `Scikit-Learn`, `Pandas`, `NumPy`, `Seaborn`.
- **Model**: Optimized Gradient Boosting & Random Forest.

## 📈 Result Snippet
- **Accuracy (R2)**: 0.96 (Gradient Boosting).
- **Core Insight**: TV advertising identified as the primary revenue generator.
