# 🏙️ Titanic Survival Prediction
Build a robust machine learning model to predict the survival status of Titanic passengers.

## 📋 Project Highlights
- **Goal**: Predict the survival (binary classification: Survived/Not Survived).
- **Optimization**: Used `GridSearchCV` to find optimal `RandomForest` parameters.
- **Top Features**: Identified **Fare** and **Age** as critical survival predictors.
- **Metrics**: Evaluated using **ROC Curves**, **Confusion Matrix**, and **Accuracy**.

## 🛠️ Technology Stack
- **Language**: Python 3.13
- **Primary Libraries**: `Scikit-Learn`, `Pandas`, `NumPy`, `Seaborn`.
- **Model**: Optimized Random Forest Classifier.

## 📊 Result Snippet
- **Accuracy**: ~70% (Cross-Validated).
- **Best Settings**: Tuned via GridSearch for maximum reliability.
