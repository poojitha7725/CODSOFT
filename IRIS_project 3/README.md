# 🌸 Iris Flower Classifier
Use machine learning to classify iris flowers based on their petal and sepal measurements.

## 📋 Project Highlights
- **Goal**: Classify Iris flowers into three species: *Setosa*, *Versicolor*, and *Virginica*.
- **Workflow**: Implemented a **Pipeline** that handles data scaling and classification in one step.
- **Optimization**: Used `GridSearchCV` to automatically find the best `Random Forest` settings.
- **Evaluation**: Visualized using a **Professional Confusion Matrix**.

## 🛠️ Technology Stack
- **Language**: Python 3.13
- **Primary Libraries**: `Scikit-Learn`, `Pandas`, `NumPy`, `Seaborn`.
- **Model**: Pipeline-Optimized Random Forest.

## 📊 Result Snippet
- **Accuracy**: 90% and above on unseen data.
- **Stability**: Cross-validated across 5 folds for reliability.
